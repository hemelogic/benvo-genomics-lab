# Benvo Genomics Lab

This repository is my personal genomics and bioinformatics lab, created in memory of my nephew Ben, who passed away from leukemia. The purpose of this repo is to document my journey from cloud, DevOps, and applied AI engineering into cancer genomics by building reproducible tools, workflows, and AI-assisted systems for learning and research. This is not medical advice or clinical software; it is a technical learning and engineering space focused on understanding leukemia genomics, public cancer datasets, workflow automation, and safe AI-assisted analysis.
